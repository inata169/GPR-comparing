## Important behavior and safety decisions

- CLI and batch retain PyMedPhys 0.41.0 as the standard omitted-value Gamma engine. The GUI defaults to parallel Numba with interpolation fraction 4 for practical full-volume runtime; PyMedPhys remains explicitly selectable and displays a slow-run warning.
- Existing external CPython 3.12 x64 may be used as the source for the application-dedicated virtual environment. The installer must not modify or uninstall that external Python installation.
- Differing present `FrameOfReferenceUID` values fail closed unless a separately implemented spatial-registration transform is supplied.
- Reference and evaluation doses are mapped from their own DICOM IPP, IOP, Pixel Spacing, and sorted GFOV into the common calculation coordinates. No DICOM-to-IEC angular coordinate conversion is performed.
- Numba requires uniform evaluation-axis spacing. A nonuniform evaluation GFOV/axis now fails closed with guidance to select PyMedPhys or resample the evaluation RTDOSE; it must not be interpreted with the first GFOV interval as a constant spacing.
- Gamma and Pass/Fail overlays require a compatible validated Gamma cache. Dose-only Viewer fallback remains available, and unavailable overlays cannot be selected through buttons, menus, or keyboard shortcuts.
- The project remains for research and education only. No clinical-use, patient-QA, commissioning, treatment-decision, medical-device, or vendor-approval claim is made.
