## Correctness change completed today

TPS testing exposed 11,377 reference cutoff-qualified points for which the reference RTDOSE had spatial coverage but the evaluation RTDOSE did not. PyMedPhys counted those points as failures. The project owner approved the rule that a location is not evaluated when either dose distribution has no value there.

PR #30 now applies one engine-neutral common patient-coordinate domain:

- a point stored as zero inside both grids remains a real value and is evaluated;
- a reference point outside the evaluation grid extent is represented as unavailable and excluded from the GPR denominator;
- PyMedPhys and Numba receive the same cutoff-qualified, common-spatial, spatially excluded, and evaluated point counts;
- reports, SQLite, saved Gamma caches, comparison tools, and Viewers preserve the distinction;
- report schema version 3 and Gamma cache contract version 2 reject incompatible pre-change cache semantics.

This change does not make PyMedPhys and Numba numerically equivalent and does not extrapolate or pad missing dose coverage.
